# R.E.A.C.T. student writing-feedback prototype

Throwaway click-through demo for teachers. Single static page; all content from `data.json`.

## Local

```bash
python3 -m http.server 8000
```

Open http://localhost:8000/

## GitHub Pages

Repo base path: `/zest-core-func-prototype/`

After pushing to `main`, the Deploy workflow publishes the site. Expected URL:

`https://<owner>.github.io/zest-core-func-prototype/`

In the repo settings, set Pages source to **GitHub Actions** if prompted.
